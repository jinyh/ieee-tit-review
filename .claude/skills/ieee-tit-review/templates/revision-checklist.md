# 修改检查清单 / Revision Checklist

## 目的 (Purpose)

帮助作者在修改论文时系统地检查所有评审意见是否已充分解决。同时也可以帮助评审人在复审时检查修改是否充分。

---

## 使用方法 / How to Use

### 对于作者 (For Authors)

1. 仔细阅读所有评审意见
2. 将每个评审意见记录在本检查清单中
3. 逐项解决每个问题
4. 在回复信中说明如何解决每个问题
5. 在修订版中标注所有修改（使用红色或高亮）

### 对于评审人 (For Reviewers)

1. 阅读作者的回复信
2. 使用本检查清单逐项检查问题是否解决
3. 在修订版中查找对应的修改
4. 评估修改是否充分
5. 做出复审决定

- [ ] **所有 Major Issues 已解决**: 检查所有 Major Issues 是否都已充分解决
- [ ] **所有 Minor Issues 已解决**: 检查所有 Minor Issues 是否都已解决

- [ ] **修改标注清晰**: 检查修订版中的修改是否都用红色标注

---

### 质量检查 (Quality Check)

- [ ] **修改充分**: 修改是否充分解决了评审人的问题
- [ ] **修改准确**: 修改是否准确理解了评审人的意图
- [ ] **修改一致**: 修改是否与论文其他部分一致

- [ ] **格式正确**: 修改后的格式是否正确

- [ ] **创新性和贡献**: 修改后贡献是否更清晰
- [ ] **实验验证**: 修改后实验是否更充分（如适用）
- [ ] **文献综述质量**: 修改后文献综述是否更完整
- [ ] **写作清晰度**: 修改后写作是否更清晰

- [ ] **页数**: 修订版页数是否符合要求

## 第六部分：常见修改错误 / Part 6: Common Revision Mistakes

### 错误1: 修改不充分 (Insufficient Revision)

**表现**:
- 只做了表面修改，没有解决根本问题
- 修改不够详细，评审人仍然不满意

**避免方法**:
- 深入理解评审人的意图
- 充分解决问题，不要敷衍
- 如果不确定，可以在回复信中询问评审人

---

### 错误2: 过度修改 (Over-revision)

**表现**:
- 修改了评审人没有要求修改的内容
- 引入了新的问题或错误

**避免方法**:
- 只修改评审人要求修改的内容
- 如果要做其他修改，在回复信中说明
- 修改后仔细检查，确保没有引入新错误

---

### 错误3: 回复信不清晰 (Unclear Response Letter)

**表现**:
- 回复信没有清楚说明如何修改
- 回复信没有指出修改的具体位置
- 回复信态度不当（如争辩、不尊重）

**避免方法**:
- 回复信要详细、清晰、具体
- 每个修改都要指出具体位置
- 保持尊重和感谢的态度

---

### 错误4: 修改标注不清 (Unclear Change Marking)

**表现**:
- 修改没有用红色标注
- 标注不完整，遗漏了一些修改
- 标注过多，包含了不必要的内容

**避免方法**:
- 所有修改都用红色标注
- 只标注实质性修改，不标注格式调整
- 确保标注完整

---

### 错误5: 不采纳建议但未说明理由 (Rejecting Suggestions Without Explanation)

**表现**:
- 不采纳评审人的建议，但没有说明理由
- 说明理由不充分或不合理

**避免方法**:
- 如果不采纳建议，必须在回复信中说明充分的理由
- 理由要合理、有说服力
- 保持尊重的态度

## 第七部分：复审准备 / Part 7: Re-review Preparation

### 提交前最后检查 (Final Check Before Submission)

- [ ] **修订版完整**: 修订版包含所有修改
- [ ] **修改标注清晰**: 所有修改都用红色标注
- [ ] **回复信完整**: 回复信对每条评审意见都有回复
- [ ] **文件命名正确**: 文件命名符合期刊要求
- [ ] **格式正确**: 修订版格式符合期刊要求
- [ ] **无遗漏**: 没有遗漏任何评审意见

---

### 提交材料清单 (Submission Materials Checklist)

- [ ] **修订版论文**: 包含所有修改，用红色标注
- [ ] **干净版论文**: 不包含红色标注的最终版本
- [ ] **回复信**: 详细回复每条评审意见
- [ ] **修改对照表**: 列出所有修改的位置（可选）
- [ ] **其他材料**: 根据期刊要求提供的其他材料

---

### 复审决策 (Re-review Decision)

根据修改情况，做出复审决策：

- [ ] **Accept**: 所有问题都已充分解决
- [ ] **Minor Revision**: 大部分问题已解决，还有少量小问题
- [ ] **Major Revision**: 部分重要问题未充分解决
- [ ] **Reject**: 核心问题未解决或修改不充分

---

## 总结 / Summary

**修改成功的关键**:
1. **充分理解评审意见**: 确保理解评审人的意图
2. **系统性修改**: 使用本检查清单系统地解决每个问题
3. **清晰的回复信**: 详细说明如何解决每个问题
4. **清晰的修改标注**: 用红色标注所有修改
5. **质量检查**: 修改后仔细检查，确保没有新问题

**记住**:
- 尊重评审人的意见
- 充分解决所有 Major Issues
- 尽量解决所有 Minor Issues
- 对 Suggestions 要么采纳，要么说明理由
- 保持专业和礼貌的态度
