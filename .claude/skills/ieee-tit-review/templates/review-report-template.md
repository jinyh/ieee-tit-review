## 主要问题 / Main Issues

### Major Issues (必须解决 / Must be addressed)

**[M1] [维度] - [问题标题]**

- **位置 / Location**: [页码、章节、公式编号]
- **问题描述 / Description**: [详细描述问题，说明为什么这是一个严重问题]
- **影响 / Impact**: [说明这个问题对论文正确性、完整性或可发表性的影响]
- **改进建议 / Suggestions**:
  1. [具体建议 1]
  2. [具体建议 2]
  3. [具体建议 3，如需要]

**示例**:

**[M1] 数学证明完整性 - 定理 3 的证明存在逻辑漏洞**

- **位置 / Location**: 第 8 页，定理 3 的证明，公式 (15)-(16)
- **问题描述 / Description**: 从公式 (15) 到 (16) 使用了 Jensen 不等式，但未验证函数的凸性条件。Jensen 不等式要求函数 f(x) 是凸函数，但论文中的函数 f(x) = -log(1+x) 在 x>0 时是凹函数，不能直接应用 Jensen 不等式。
- **影响 / Impact**: 这是定理 3 证明的关键步骤，如果不等式方向错误，定理 3 的结论可能不成立，影响论文的核心贡献。
- **改进建议 / Suggestions**:
  1. 重新检查函数的凸性，如果是凹函数，应使用 Jensen 不等式的凹函数形式（不等号方向相反）
  2. 或者考虑使用其他不等式（如 Hölder 不等式）来完成证明
  3. 在证明中明确说明所使用的数学工具的适用条件

[在这里提供总体性的建议和鼓励。即使是拒稿，也要保持建设性和尊重。]

**示例 (Accept/Minor)**:
> 这是一篇高质量的论文，对信息论领域有显著贡献。论文的理论分析严谨，证明完整，写作清晰。建议作者在修订版中解决上述 Minor Issues，进一步提升论文质量。我期待看到修订版。

**示例 (Reject)**:
> 感谢作者的投稿。论文研究的问题有一定意义，但目前的理论贡献不足以达到 IEEE TIT 的发表标准。主要问题是论文的结果与现有工作 [Ref X] 相比仅有增量改进，缺乏显著的理论创新。建议作者考虑将论文投稿到应用导向更强的期刊，或者进一步深化理论分析，提供更显著的贡献。
