# IEEE TIT 论文快速检查清单 (Quick Checklist)

## 目的 (Purpose)

本清单用于**快速评审**和**初步筛选**，包含 25 个最关键的检查项。适用于：
- 时间紧迫的评审
- 投稿前自查
- 初步筛选阶段
- 快速判断论文质量

如果快速检查发现关键问题，应使用详细检查清单进一步验证。

---

## 一、理论严谨性 (5 项核心检查)

### ✅ 1.1 定义完备性
- [ ] 所有关键概念都有明确定义
- [ ] 定义没有循环依赖
- [ ] 定义覆盖所有使用场景

**检查方法**: 搜索论文中的关键术语，确认每个术语在首次出现时有定义

### ✅ 1.2 假设条件明确性
- [ ] 所有定理的假设条件在定理陈述中明确列出
- [ ] 假设条件不过强（不是显然不可能满足的）
- [ ] 假设条件的必要性有说明

**检查方法**: 阅读每个定理陈述，检查假设条件是否完整

### ✅ 1.3 定理陈述精确性
- [ ] 定理陈述使用精确的数学语言
- [ ] 量词（∀, ∃）使用正确
- [ ] 边界条件明确（等号是否包含）

**检查方法**: 检查定理陈述中是否有模糊表述

### ✅ 1.4 逻辑一致性
- [ ] 论文中没有自相矛盾的陈述
- [ ] 定理之间的关系清晰（哪个是哪个的推论）
- [ ] 没有循环论证

**检查方法**: 检查定理之间的引用关系

### ✅ 1.5 特殊情况处理
- [ ] 考虑了边界情况（如 n→∞, p→0, p→1）
- [ ] 考虑了退化情况（如矩阵奇异、信道容量为 0）
- [ ] 对特殊情况有明确说明

**检查方法**: 检查论文是否讨论了极端情况

---

## 二、数学证明完整性 (5 项核心检查)

### ✅ 2.1 主定理证明完整
- [ ] 所有主定理都有完整证明（正文或附录）
- [ ] 证明不依赖未证明的引理
- [ ] 关键步骤没有标注"证明略"

**检查方法**: 检查每个定理后是否有"Proof"和"□"或"QED"

### ✅ 2.2 数学工具适用性
- [ ] Jensen 不等式：验证了凸性条件
- [ ] Fano 不等式：验证了适用范围
- [ ] 极限交换：验证了 Dominated Convergence Theorem 条件
- [ ] Markov 链：验证了遍历性或平稳性

**检查方法**: 搜索这些数学工具，检查是否验证了适用条件

### ✅ 2.3 证明步骤可验证性
- [ ] 每个推导步骤都有依据（引理、定理、已知结果）
- [ ] 复杂推导有中间步骤
- [ ] 没有"显然"、"容易验证"、"直接可得"等模糊表述

**检查方法**: 随机选择 3-5 个证明步骤，检查是否可以跟随

### ✅ 2.4 引理和辅助结果
- [ ] 所有引理都有证明
- [ ] 引理的作用清晰（为哪个定理服务）
- [ ] 没有未使用的引理

**检查方法**: 检查每个引理是否被后续定理引用

### ✅ 2.5 证明结构清晰
- [ ] 长证明有证明思路或关键步骤概述
- [ ] 证明分段合理（如"充分性"和"必要性"分开）
- [ ] 证明结束有明确标记

**检查方法**: 检查长证明（>1 页）是否有结构说明

---

## 三、创新性和贡献 (5 项核心检查)

### ✅ 3.1 问题新颖性
- [ ] 问题是新的，或者是已知问题的重要扩展
- [ ] 问题的重要性有充分说明
- [ ] 问题与现有工作的区别清晰

**检查方法**: 阅读引言，检查问题定位是否清晰

### ✅ 3.2 理论贡献显著性
- [ ] 贡献是理论性的（新界、新方法、新洞察）
- [ ] 不是仅仅改进常数因子
- [ ] 不是仅仅扩展到特殊情况

**检查方法**: 检查主要结果是否有本质性的理论进展

### ✅ 3.3 与现有工作的对比
- [ ] 引言中有与现有最佳结果的对比
- [ ] 对比说明了本质区别（不仅是数值改进）
- [ ] 对比是公平的（相同假设条件下）

**检查方法**: 检查引言中是否有对比表格或详细对比

### ✅ 3.4 技术创新性
- [ ] 使用了新的证明技术或分析工具
- [ ] 技术有通用性（可应用到其他问题）
- [ ] 技术不是简单组合现有方法

**检查方法**: 检查证明中是否有新颖的技术步骤

### ✅ 3.5 结果的意外性
- [ ] 结果挑战了直觉或常规认知
- [ ] 结果揭示了新现象或新规律
- [ ] 结果有理论或实践意义

**检查方法**: 检查论文是否讨论了结果的意义和影响

---

## 四、文献综述质量 (5 项核心检查)

### ✅ 4.1 开创性工作引用
- [ ] 引用了该问题的开创性工作（如 Shannon 1948）
- [ ] 引用了相关领域的经典文献
- [ ] 引用是准确的（不是二手引用）

**检查方法**: 检查参考文献中是否有经典文献

### ✅ 4.2 最接近相关工作
- [ ] 引用了最接近的相关工作
- [ ] 详细说明了与最接近工作的区别
- [ ] 没有遗漏明显的相关工作

**检查方法**: 检查引言中是否详细讨论了最相关的 2-3 篇文献

### ✅ 4.3 最新进展引用
- [ ] 引用了近 3-5 年的最新进展
- [ ] 引用的文献是该领域的主流期刊/会议
- [ ] 没有遗漏重要的最新工作

**检查方法**: 检查参考文献中是否有 2021 年后的文献

### ✅ 4.4 引用准确性
- [ ] 引用格式符合 IEEE 标准
- [ ] 引用位置准确（在正确的地方引用）
- [ ] 没有错误引用（引用内容与文献不符）

**检查方法**: 随机抽查 3-5 个引用，检查是否准确

### ✅ 4.5 文献综述完整性
- [ ] 覆盖了该问题的主要研究方向
- [ ] 展示了问题的发展历史
- [ ] 清楚定位了本文的贡献

**检查方法**: 检查引言中是否有系统的文献综述

---

## 五、写作清晰度 (5 项核心检查)

### ✅ 5.1 符号系统一致性
- [ ] 同一符号在全文中含义一致
- [ ] 不同概念使用不同符号
- [ ] 有符号表（建议在引言后）

**检查方法**: 搜索常见符号（H, I, D, C, R），检查是否一致使用

### ✅ 5.2 摘要和引言清晰度
- [ ] 摘要对非专家读者清晰
- [ ] 引言说明了问题背景和重要性
- [ ] 引言列出了主要贡献

**检查方法**: 阅读摘要和引言，检查是否易懂

### ✅ 5.3 定理陈述自包含性
- [ ] 定理陈述不依赖前文的隐含假设
- [ ] 定理中的符号都有定义
- [ ] 定理可以独立理解

**检查方法**: 随机选择 2-3 个定理，检查是否可以独立理解

### ✅ 5.4 图表质量
- [ ] 所有图表都有标题和说明
- [ ] 图表是自解释的（不依赖正文）
- [ ] 图表清晰、专业

**检查方法**: 检查每个图表是否有完整的 caption

### ✅ 5.5 逻辑流程连贯性
- [ ] 章节之间衔接自然
- [ ] 没有突兀的跳跃
- [ ] 有过渡段落或句子

**检查方法**: 检查章节开头是否有承上启下的段落

## 快速评分指南 (Quick Scoring Guide)

### 通过标准
- ✅ **25 项全部通过**: 论文质量优秀，进入详细评审
- ✅ **22-24 项通过**: 论文质量良好，有小问题需要修正
- ⚠️ **18-21 项通过**: 论文质量中等，需要 Minor Revision
- ⚠️ **15-17 项通过**: 论文有较多问题，需要 Major Revision
- ❌ **<15 项通过**: 论文质量不足，建议 Reject

### 致命缺陷（任何一项未通过即建议 Reject）
1. 主定理证明缺失或有明显逻辑漏洞
2. 创新性不足（仅是增量改进）
3. 遗漏了明显的重要相关工作
4. 符号系统严重混乱
5. 不属于信息论领域

## 使用建议 (Usage Tips)

### 何时使用快速检查清单
1. **初步筛选**: 快速判断论文是否值得详细评审
2. **时间紧迫**: 需要在短时间内给出初步意见
3. **投稿前自查**: 作者在投稿前快速检查论文质量
4. **学生指导**: 导师快速检查学生论文的基本质量

### 何时使用详细检查清单
1. **正式评审**: 作为评审人进行正式的同行评审
2. **发现问题**: 快速检查发现了关键问题，需要深入分析
3. **高质量论文**: 快速检查全部通过，需要进一步细致评审
4. **复审**: 评审修订版论文，需要逐项检查问题是否解决

### 检查顺序建议
1. **先检查致命缺陷**: 如果有致命缺陷，可以直接停止
2. **再检查理论严谨性和证明完整性**: 这是 IEEE TIT 的核心要求
3. **最后检查其他维度**: 创新性、文献、写作
