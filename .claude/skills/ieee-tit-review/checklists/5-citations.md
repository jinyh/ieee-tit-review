# 引用规范性检查清单 / Citation Standards Checklist

## 目的 (Purpose)

检查论文的文献综述是否完整，引用是否准确、规范，是否遗漏重要相关工作。这对于 IEEE TIT 论文非常重要，因为必须准确定位论文的贡献。

## 使用方法 (How to Use)

1. 检查文献综述的完整性
2. 检查引用的准确性和规范性
3. 识别遗漏的重要文献
4. 记录发现的问题

---

## 1. 文献综述完整性 / Literature Review Completeness

### 1.1 开创性工作 (Pioneering Work)

- [ ] **领域奠基人**: 引用了该领域的奠基性工作
- [ ] **问题起源**: 引用了该问题的最早研究
- [ ] **经典结果**: 引用了相关的经典结果

**IEEE TIT 要求**:
- ✅ 必须引用该问题的**开创性工作**
- ✅ 必须引用领域的**奠基性论文**

**信息论领域的经典文献**:
- Shannon 1948: "A Mathematical Theory of Communication"
- Cover & Thomas: "Elements of Information Theory"
- Gallager: "Information Theory and Reliable Communication"
- 根据具体问题引用相关的开创性工作

**常见问题**:
- 未引用 Shannon 的开创性工作
- 未引用该问题的最早研究
- 未引用经典教材或综述

---

### 1.2 最接近的相关工作 (Most Related Work)

- [ ] **直接相关**: 引用了最接近的相关工作
- [ ] **对比说明**: 清楚说明与最接近工作的区别
- [ ] **改进说明**: 说明本文相对于最接近工作的改进

**IEEE TIT 要求**:
- ✅ 必须引用**最接近的相关工作**并说明区别
- ✅ 必须清楚说明本文的**本质区别**和**改进**
- ❌ 拒绝声称"首次研究"但遗漏了明显的相关工作

**检查方法**:
- 搜索相关关键词，查找最接近的工作
- 检查最接近工作的引用文献
- 检查引用本文作者之前工作的论文

**常见问题**:
- 遗漏了最接近的相关工作
- 未清楚说明与相关工作的区别
- 声称"首次研究"但实际上有相关工作

---

### 1.3 最新进展 (Recent Advances)

- [ ] **近3年文献**: 引用了近3年的相关文献
- [ ] **近5年文献**: 引用了近5年的相关文献
- [ ] **最新SOTA**: 引用了最新的SOTA方法

**IEEE TIT 要求**:
- ✅ 必须引用**最新的进展**（近3-5年）
- ✅ 必须说明本文与最新工作的关系

**检查方法**:
- 在 Google Scholar、IEEE Xplore 搜索相关关键词
- 按时间排序，检查近3-5年的文献
- 检查是否有遗漏的重要最新工作

**常见问题**:
- 引用的文献过于陈旧
- 未引用最新的SOTA方法
- 未说明与最新工作的关系

---

### 1.4 相关方向的工作 (Related Directions)

- [ ] **相关问题**: 引用了相关问题的工作
- [ ] **相关方法**: 引用了相关方法的工作
- [ ] **相关应用**: 引用了相关应用的工作

**覆盖范围**:
- 同一问题的不同方法
- 相关问题的类似方法
- 相关理论工具的应用
- 相关应用领域的工作

**常见问题**:
- 文献综述过于狭窄
- 未引用相关方向的重要工作
- 未说明与相关方向的联系

---

### 1.5 文献综述的组织 (Organization of Literature Review)

- [ ] **分类清晰**: 相关工作按类别组织
- [ ] **逻辑连贯**: 文献综述的逻辑流程清晰
- [ ] **对比表格**: 使用表格对比本文与现有工作（推荐）
- [ ] **研究脉络**: 展示问题的研究脉络和发展历史

**推荐结构**:
1. 开创性工作和经典结果
2. 按方法或问题分类的相关工作
3. 最新进展
4. 本文的定位和贡献

**对比表格示例**:
| 文献 | 信道模型 | 编码方案 | 容量界 | 复杂度 |
|------|---------|---------|--------|--------|
| [Ref 1] | AWGN | Turbo | 下界 | O(n²) |
| [Ref 2] | Fading | LDPC | 上界 | O(n log n) |
| 本文 | MIMO | Polar | 精确 | O(n log n) |

**常见问题**:
- 文献综述缺乏组织，像流水账
- 未使用表格对比（推荐但非必需）
- 未展示研究脉络

## 2. 引用准确性 / Citation Accuracy

### 2.1 引用内容准确 (Content Accuracy)

- [ ] **结果准确**: 引用的结果准确无误
- [ ] **作者准确**: 引用的作者准确无误
- [ ] **年份准确**: 引用的年份准确无误
- [ ] **出处准确**: 引用的出处（期刊/会议）准确无误

**检查方法**:
- 抽查重要引用，验证内容是否准确
- 检查作者姓名拼写
- 检查年份和出处

**常见错误**:
- 引用的结果与原文不符
- 作者姓名拼写错误
- 年份错误
- 期刊/会议名称错误

---

### 2.2 引用位置恰当 (Appropriate Placement)

- [ ] **声明有引用**: 所有非原创的声明都有引用
- [ ] **引用位置正确**: 引用放在正确的位置（句末或关键词后）
- [ ] **避免过度引用**: 避免在一句话中引用过多文献
- [ ] **避免引用不足**: 重要声明必须有引用

**引用位置规范**:
- 引用放在句末：`...结果 [1].`
- 引用放在关键词后：`Shannon [1] 证明了...`
- 多个引用：`...结果 [1], [2], [3].` 或 `...结果 [1]-[3].`

**常见问题**:
- 非原创声明缺少引用
- 引用位置不当
- 一句话引用过多文献（如 [1]-[20]）

---

### 2.3 自引用合理性 (Self-Citation Reasonableness)

- [ ] **自引用必要**: 自引用是必要的（引用自己的相关工作）
- [ ] **自引用比例**: 自引用比例合理（通常不超过20%）
- [ ] **避免过度自引**: 避免不必要的自引用

**合理的自引用**:
- 引用自己之前在该问题上的工作
- 引用自己开发的方法或工具
- 引用自己的相关结果

**不合理的自引用**:
- 引用与本文无关的自己的工作
- 过度引用自己的工作
- 为了增加引用数而自引

**常见问题**:
- 自引用比例过高
- 引用与本文无关的自己的工作

---

## 3. 引用格式规范 / Citation Format Standards

### 3.1 IEEE 引用格式 (IEEE Citation Format)

IEEE 使用数字引用格式，引用按出现顺序编号。

#### 期刊论文 (Journal Papers)

**格式**:
```
[序号] 作者, "标题," 期刊名（斜体）, vol. X, no. Y, pp. Z1-Z2, 月份 年份.
```

**示例**:
```
[1] C. E. Shannon, "A mathematical theory of communication," Bell Syst. Tech. J., vol. 27, no. 3, pp. 379-423, Jul. 1948.
```

**检查要点**:
- [ ] 作者姓名格式正确（首字母缩写 + 姓）
- [ ] 标题使用引号，首字母大写
- [ ] 期刊名使用斜体或下划线
- [ ] 卷号、期号、页码完整
- [ ] 月份缩写（Jan., Feb., Mar., ...）
- [ ] 年份正确

---

#### 会议论文 (Conference Papers)

**格式**:
```
[序号] 作者, "标题," in Proc. 会议名（斜体）, 地点, 年份, pp. Z1-Z2.
```

**示例**:
```
[2] E. Arikan, "Channel polarization: A method for constructing capacity-achieving codes for symmetric binary-input memoryless channels," in Proc. IEEE Int. Symp. Inf. Theory (ISIT), Toronto, ON, Canada, Jul. 2008, pp. 1173-1177.
```

**检查要点**:
- [ ] 使用 "in Proc." 或 "in"
- [ ] 会议名使用斜体或下划线
- [ ] 地点包含城市、州/省（如适用）、国家
- [ ] 月份和年份
- [ ] 页码

---

#### 书籍 (Books)

**格式**:
```
[序号] 作者, 书名（斜体）. 出版地: 出版社, 年份.
```

**示例**:
```
[3] T. M. Cover and J. A. Thomas, Elements of Information Theory, 2nd ed. Hoboken, NJ, USA: Wiley, 2006.
```

**检查要点**:
- [ ] 书名使用斜体或下划线
- [ ] 版本信息（如 2nd ed.）
- [ ] 出版地和出版社
- [ ] 年份

---

#### 书籍章节 (Book Chapters)

**格式**:
```
[序号] 作者, "章节标题," in 书名（斜体）, 编者, Ed. 出版地: 出版社, 年份, pp. Z1-Z2.
```

---

#### 技术报告 (Technical Reports)

**格式**:
```
[序号] 作者, "标题," 机构, 地点, 技术报告编号, 年份.
```

---

#### 预印本 (Preprints)

**格式**:
```
[序号] 作者, "标题," arXiv:编号, 年份.
```

**示例**:
```
[4] A. Author and B. Author, "Title of the paper," arXiv:2301.12345, 2023.
```

---

#### 在线资源 (Online Resources)

**格式**:
```
[序号] 作者或机构, "标题," 网站名, 访问日期. [Online]. Available: URL
```

**示例**:
```
[5] IEEE, "IEEE Transactions on Information Theory," Accessed: Jan. 15, 2026. [Online]. Available: https://ieeexplore.ieee.org/xpl/RecentIssue.jsp?punumber=18
```

---

### 3.2 引用格式一致性 (Format Consistency)

- [ ] **格式统一**: 所有引用使用相同的格式
- [ ] **缩写统一**: 期刊/会议名缩写统一
- [ ] **标点统一**: 标点符号使用统一
- [ ] **字体统一**: 斜体、粗体使用统一

**常见不一致**:
- 有的引用有页码，有的没有
- 有的期刊名缩写，有的全称
- 有的有月份，有的没有
- 标点符号不统一

---

### 3.3 引用信息完整性 (Information Completeness)

- [ ] **作者完整**: 所有作者都列出（或使用 et al.）
- [ ] **标题完整**: 标题完整且准确
- [ ] **出处完整**: 期刊/会议名、卷号、期号、页码完整
- [ ] **年份**: 年份正确

**IEEE 规范**:
- 如果作者超过6人，列出前6人，然后使用 "et al."
- 标题保持原文的大小写（除首字母）
- 期刊名可以使用标准缩写

**常见问题**:
- 缺少页码
- 缺少卷号或期号
- 缺少月份
- 作者列表不完整

## 4. 特殊引用检查 / Special Citation Checks

### 4.1 公式和定理的引用 (Citing Equations and Theorems)

- [ ] **引用格式**: 公式引用格式正确（如 "由公式 (15)"）
- [ ] **定理引用**: 定理引用格式正确（如 "由定理 3"）
- [ ] **外部引用**: 引用其他论文的公式/定理时格式正确（如 "由 [1, Theorem 2]"）

**推荐格式**:
- 本文公式: "由公式 (15)" 或 "由 (15)"
- 本文定理: "由定理 3" 或 "根据定理 3"
- 外部公式: "由 [1, Eq. (10)]"
- 外部定理: "由 [1, Theorem 2]"

---

### 4.2 图表的引用 (Citing Figures and Tables)

- [ ] **引用格式**: 图表引用格式正确
- [ ] **所有图表被引用**: 正文中引用了所有图表
- [ ] **引用位置**: 图表在引用后出现

**推荐格式**:
- 本文图: "如图 3 所示" 或 "见图 3"
- 本文表: "如表 2 所示" 或 "见表 2"
- 外部图表: "见 [1, Fig. 5]"

---

### 4.3 附录的引用 (Citing Appendices)

- [ ] **引用格式**: 附录引用格式正确
- [ ] **附录存在**: 引用的附录确实存在

**推荐格式**:
- "证明见附录 A" 或 "详见附录 A"
- "Appendix A" 或 "Appendix"

---

## 5. 遗漏文献检查 / Missing Literature Check

### 5.1 系统性搜索 (Systematic Search)

**搜索策略**:
1. **关键词搜索**: 在 Google Scholar、IEEE Xplore 搜索关键词
2. **引用追踪**: 检查重要文献的引用和被引文献
3. **作者追踪**: 检查该领域主要作者的工作
4. **会议/期刊追踪**: 检查相关会议和期刊的近期论文

**关键数据库**:
- Google Scholar
- IEEE Xplore
- arXiv
- Web of Science
- Scopus

---

### 5.2 重要遗漏识别 (Identifying Important Omissions)

- [ ] **开创性工作**: 是否遗漏开创性工作
- [ ] **最接近工作**: 是否遗漏最接近的工作
- [ ] **最新工作**: 是否遗漏最新的工作
- [ ] **主要作者**: 是否遗漏该领域主要作者的工作

**严重程度判断**:
- **Major**: 遗漏开创性工作或最接近的工作
- **Minor**: 遗漏相关但不是最接近的工作
- **Suggestion**: 遗漏可以增强文献综述的工作

## 文献综述质量评分标准 / Literature Review Quality Scoring

### 10分 (优秀 / Excellent)
- 文献综述全面、完整
- 引用了所有重要文献（开创性、最接近、最新）
- 清楚说明了本文与现有工作的区别
- 引用准确、格式规范

### 7-9分 (良好 / Good)
- 文献综述比较完整
- 引用了大部分重要文献
- 基本说明了本文的定位
- 引用基本准确，格式基本规范

### 4-6分 (需改进 / Needs Improvement)
- 文献综述不够完整
- 遗漏了一些重要文献
- 未清楚说明本文的定位
- 引用有一些错误或格式问题

### 1-3分 (不合格 / Unacceptable)
- 文献综述严重不完整
- 遗漏了关键文献（开创性或最接近）
- 未说明本文的定位和贡献
- 引用有严重错误
