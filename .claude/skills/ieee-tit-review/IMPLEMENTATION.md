## 核心特色

### 1. 体现 IEEE TIT 特色

✅ **理论深度优先**: 强调显著的理论创新，不接受增量改进
✅ **数学严谨性**: 所有定理必须有完整且严格的证明
✅ **可读性要求**: 技术深度高，但必须对广泛读者清晰
✅ **创新性判断**: 区分突破性贡献、显著贡献和增量贡献
✅ **文献综述完整**: 必须引用开创性工作、最接近工作和最新进展

### 2. 完整的评审框架

✅ **六大评审维度**: 覆盖理论、证明、创新、实验、文献、写作
✅ **三级反馈结构**: Major/Minor/Suggestion 清晰分级
✅ **四阶段工作流程**: 从初步筛选到复审的完整流程
✅ **结构化报告**: 中英双语模板，便于使用

### 3. 实用的检查清单

✅ **六个独立检查清单**: 可以单独使用或组合使用
✅ **200+ 检查项**: 覆盖论文的各个方面
✅ **问题记录表**: 方便记录和追踪问题
✅ **评分标准**: 每个维度都有明确的评分标准

### 4. 中英双语

✅ **关键术语保留英文**: 便于国际交流
✅ **说明使用中文**: 便于理解和使用
✅ **模板双语**: 评审报告模板中英双语

## 使用场景

### ✅ 适用场景

1. **投稿前自查**: 作者在投稿 IEEE TIT 前使用检查清单自查
2. **同行评审**: 评审人评审 IEEE TIT 投稿时使用完整框架
3. **论文指导**: 导师指导学生撰写信息论论文
4. **学习参考**: 学习如何撰写高质量的理论论文
5. **模拟评审**: 对学生论文进行模拟评审

### ❌ 不适用场景

1. 非信息论领域的论文
2. 会议论文（ISIT, ITW 等，标准不同）
3. 其他 IEEE 期刊（JSAC, Communications Letters 等）
4. 快速浏览或初步筛选（本 skill 适用于深度评审）
