# 证明逻辑检查清单 / Proof Logic Checklist

## 目的 (Purpose)

检查论文中所有定理、引理、推论的证明是否完整、严格、逻辑正确。这是 **IEEE TIT 评审的核心**，任何证明漏洞都是 Major Issue。

## 使用方法 (How to Use)

1. 列出论文中所有的定理、引理、推论
2. 逐个检查每个证明
3. 记录发现的问题
4. 评估证明的整体质量

---

## 1. 定理陈述完整性 / Theorem Statement Completeness

### 1.1 定理陈述自包含性 (Self-Containedness)

- [ ] **所有假设明确列出**: 定理陈述中包含所有必要的假设条件
- [ ] **不依赖隐含假设**: 定理不依赖前文未明确说明的假设
- [ ] **量词使用正确**: ∀ (对于所有) 和 ∃ (存在) 使用正确
- [ ] **边界条件明确**: 定理的适用范围和边界条件明确

**IEEE TIT 要求**:
- ✅ 定理陈述必须自包含，读者应该能够仅从定理陈述理解其含义
- ✅ 所有假设条件必须在定理中明确列出，不能隐含在前文

**常见问题**:
- 定理依赖第 2 节的假设 A1，但定理陈述中未提及
- 量词使用不当：应该是"对于所有 ε > 0"而非"对于 ε > 0"
- 边界条件不明确：定理在 n → ∞ 时成立，但未说明

**示例**:

❌ **不好的陈述**:
> **定理 1**: 容量为 C = log(1 + SNR)。

✅ **好的陈述**:
> **定理 1**: 对于加性高斯白噪声信道，在功率约束 P 下，信道容量为
> C = (1/2) log(1 + P/N₀)，
> 其中 N₀ 是噪声功率谱密度。

---

### 1.2 定理陈述精确性 (Precision)

- [ ] **结论明确**: 定理的结论清晰、明确、无歧义
- [ ] **等式/不等式正确**: 等号、不等号使用正确
- [ ] **渐近符号准确**: O(·), Θ(·), o(·) 等使用准确
- [ ] **常数明确**: 涉及的常数是否明确（如"存在常数 C"）

**常见问题**:
- 使用 O(n) 但实际应该是 Θ(n)
- 说"容量约为 C"而非"容量等于 C"
- 说"存在常数"但未说明常数依赖什么参数

---

## 2. 证明完整性 / Proof Completeness

### 2.1 所有定理都有证明 (All Theorems Proved)

- [ ] **主定理有证明**: 所有主定理都有完整证明
- [ ] **引理有证明**: 所有引理都有证明
- [ ] **推论有证明**: 所有推论都有证明或说明如何从定理推出

**IEEE TIT 要求**:
- ✅ 所有定理必须有完整证明（正文或附录）
- ❌ 不接受"证明略"、"证明留给读者"、"证明类似于 [Ref X]"

**例外情况**:
- 引用已知结果（必须给出准确的引用）
- 推论直接从定理得出（必须说明如何得出）

---

### 2.2 证明结构清晰 (Clear Proof Structure)

- [ ] **证明思路**: 复杂证明有证明思路或关键步骤概述
- [ ] **证明分步**: 长证明分成清晰的步骤
- [ ] **步骤标注**: 主要步骤有标注（如"步骤 1"、"步骤 2"）
- [ ] **证明结束标记**: 证明结束有标记（如 □ 或 ∎）

**推荐结构**:
```
**定理 X 的证明**:

*证明思路*: [简要说明证明的主要思路和关键技巧]

*步骤 1*: [第一步的目标和方法]
[详细推导...]

*步骤 2*: [第二步的目标和方法]
[详细推导...]

*步骤 3*: [第三步的目标和方法]
[详细推导...]

综合以上步骤，定理得证。□
```

---

## 3. 证明逻辑严密性 / Proof Logical Rigor

### 3.1 推导步骤完整 (Complete Derivation Steps)

- [ ] **无跳步**: 每个推导步骤都有明确依据
- [ ] **中间步骤**: 复杂推导有足够的中间步骤
- [ ] **步骤依据**: 每个不等式/等式都说明依据

**IEEE TIT 要求**:
- ❌ 禁止使用"显然"、"容易验证"、"直接可得"等模糊表述
- ✅ 每个推导步骤都应该有明确依据（引理、定理、已知结果、数学工具）

**常见问题**:
- 从公式 (15) 直接跳到公式 (18)，缺少中间步骤
- 说"显然有 X ≤ Y"但不明显
- 复杂的代数推导没有中间步骤

**示例**:

❌ **不好的证明**:
> 由公式 (15)，显然有公式 (16)。

✅ **好的证明**:
> 由公式 (15)，我们有
> H(X|Y) = H(X,Y) - H(Y)                    (a)
>        ≤ H(X) + H(Y) - H(Y)               (b)
>        = H(X),                             (c)
> 其中 (a) 由链式法则，(b) 由 H(X,Y) ≤ H(X) + H(Y)，(c) 由代数化简。

---

### 3.2 数学工具使用正确 (Correct Use of Mathematical Tools)

检查以下常用数学工具的使用是否正确：

#### 不等式 (Inequalities)

- [ ] **Jensen 不等式**: 验证函数的凸性/凹性条件
- [ ] **Hölder 不等式**: 验证共轭指数条件
- [ ] **Cauchy-Schwarz 不等式**: 验证内积空间条件
- [ ] **Markov 不等式**: 验证非负随机变量条件
- [ ] **Chebyshev 不等式**: 验证方差存在性
- [ ] **Fano 不等式**: 验证适用条件

**常见错误**:
- 对凹函数使用 Jensen 不等式但不等号方向错误
- 使用 Hölder 不等式但 p 和 q 不满足 1/p + 1/q = 1
- 对可能为负的随机变量使用 Markov 不等式

---

#### 极限和连续性 (Limits and Continuity)

- [ ] **极限交换**: 验证极限交换的条件（如一致收敛）
- [ ] **积分和极限交换**: 验证 Dominated Convergence Theorem 的条件
- [ ] **求和和极限交换**: 验证交换条件
- [ ] **连续性**: 验证函数连续性假设

**常见错误**:
- 未验证条件就交换极限和积分的顺序
- 假设函数连续但未验证
- 点态收敛和一致收敛混淆

---

#### 概率论工具 (Probability Theory Tools)

- [ ] **大数定律**: 验证独立同分布和期望存在性
- [ ] **中心极限定理**: 验证独立同分布和方差有限性
- [ ] **Borel-Cantelli 引理**: 验证事件独立性或概率和收敛
- [ ] **条件期望**: 验证可测性和可积性

**常见错误**:
- 使用大数定律但随机变量不独立
- 使用中心极限定理但方差不存在
- 条件期望的可测性问题

---

#### 信息论工具 (Information Theory Tools)

- [ ] **链式法则**: H(X,Y) = H(X) + H(Y|X)
- [ ] **数据处理不等式**: I(X;Y) ≥ I(X;Z) 当 X → Y → Z 形成马尔可夫链
- [ ] **Fano 不等式**: H(X|Y) ≤ H(P_e) + P_e log(|𝒳| - 1)
- [ ] **互信息的凸性/凹性**: I(X;Y) 关于 P_X 是凹的，关于 P_{Y|X} 是凸的

**常见错误**:
- 使用数据处理不等式但未验证马尔可夫链条件
- Fano 不等式的不等号方向错误
- 互信息的凸性/凹性混淆

---

### 3.3 逻辑推理正确 (Correct Logical Reasoning)

- [ ] **充分性和必要性**: 区分"如果...那么..."和"当且仅当"
- [ ] **反证法**: 反证法的假设和推导正确
- [ ] **归纳法**: 数学归纳法的基础步骤和归纳步骤完整
- [ ] **构造性证明**: 构造的对象确实满足要求
- [ ] **存在性证明**: 存在性证明的逻辑正确

**常见错误**:
- 证明了充分性但声称证明了充要性
- 反证法中假设错误
- 归纳法缺少基础步骤或归纳步骤
- 构造的对象不满足所有要求

---

### 3.4 避免循环论证 (Avoid Circular Reasoning)

- [ ] **无循环定义**: 定义不依赖被定义的对象
- [ ] **无循环证明**: 证明不依赖要证明的结论
- [ ] **引理顺序**: 引理的使用顺序正确（不能在证明引理 A 时使用引理 B，而引理 B 的证明又依赖引理 A）

**常见错误**:
- 在证明定理 X 时使用了定理 X 的结论
- 定义 A 依赖定义 B，定义 B 又依赖定义 A

---

## 4. 边界条件和特殊情况 / Boundary Conditions and Special Cases

### 4.1 边界条件检查 (Boundary Condition Check)

- [ ] **n → ∞**: 渐近结果的边界行为
- [ ] **ε → 0**: 小参数极限的行为
- [ ] **SNR → ∞ 或 SNR → 0**: 高/低信噪比极限
- [ ] **P → 0 或 P → ∞**: 功率极限
- [ ] **其他参数极限**: 其他参数的极限行为

**检查要点**:
- 定理在边界条件下是否仍然成立？
- 是否有奇异性（如除以零）？
- 极限是否存在？

---

### 4.2 特殊情况检查 (Special Case Check)

- [ ] **退化情况**: 定理在退化情况下是否成立（如 Y = X 时）
- [ ] **简单情况**: 定理在简单情况下是否给出已知结果（如二元情况）
- [ ] **对称情况**: 定理在对称情况下是否给出对称结果

**检查方法**:
- 将定理应用到简单的特例，看是否得到合理结果
- 检查定理是否与已知结果一致

---

### 4.3 反例检查 (Counterexample Check)

- [ ] **是否有反例**: 定理的逆命题是否有反例
- [ ] **假设必要性**: 每个假设是否都是必要的（去掉某个假设是否有反例）
- [ ] **紧性**: 界是否是紧的（是否存在达到界的情况）

---

## 5. 证明技巧和优雅性 / Proof Techniques and Elegance

### 5.1 证明方法选择 (Choice of Proof Method)

- [ ] **方法合适**: 证明方法适合问题
- [ ] **方法简洁**: 证明方法尽可能简洁
- [ ] **方法通用**: 证明方法具有通用性（可以应用到其他问题）

**常见证明方法**:
- 直接证明
- 反证法
- 数学归纳法
- 构造性证明
- 概率方法
- 对偶方法
- 变分方法

---

### 5.2 证明可读性 (Proof Readability)

- [ ] **逻辑清晰**: 证明的逻辑流程清晰
- [ ] **步骤连贯**: 步骤之间衔接自然
- [ ] **直观解释**: 关键步骤有直观解释
- [ ] **避免冗长**: 避免不必要的冗长推导

---

## 6. 常见证明错误 / Common Proof Errors

### 6.1 不等式方向错误 (Inequality Direction Error)

- [ ] **Jensen 不等式方向**: 凸函数和凹函数的不等号方向
- [ ] **单调性**: 函数单调性导致的不等号方向
- [ ] **负号**: 乘以负数后不等号方向改变

---

### 6.2 量词错误 (Quantifier Error)

- [ ] **∀ 和 ∃ 顺序**: "对于所有 x 存在 y" vs "存在 y 对于所有 x"
- [ ] **量词范围**: 量词的作用范围是否明确

**示例**:
- ❌ 错误: "存在 δ > 0 使得对于所有 ε > 0，|f(x) - L| < ε"
- ✅ 正确: "对于所有 ε > 0，存在 δ > 0 使得 |f(x) - L| < ε"

---

### 6.3 条件遗漏 (Missing Conditions)

- [ ] **隐含假设**: 是否有未明确说明的隐含假设
- [ ] **适用条件**: 数学工具的适用条件是否满足
- [ ] **定义域**: 函数的定义域是否正确

---

### 6.4 符号滥用 (Notation Abuse)

- [ ] **同一符号多义**: 同一符号在证明中表示不同含义
- [ ] **符号未定义**: 证明中使用了未定义的符号
- [ ] **符号冲突**: 证明中的符号与前文冲突

## 证明质量评分标准 / Proof Quality Scoring

### 10分 (优秀 / Excellent)
- 所有定理都有完整、严格的证明
- 证明逻辑清晰，步骤完整
- 数学工具使用正确
- 证明具有创新性和优雅性

### 7-9分 (良好 / Good)
- 所有定理都有证明
- 证明基本正确，有少量小问题
- 数学工具使用基本正确
- 证明可读性好

### 4-6分 (需改进 / Needs Improvement)
- 部分定理证明不完整
- 证明有一些逻辑问题
- 数学工具使用有错误
- 证明可读性一般

### 1-3分 (不合格 / Unacceptable)
- 关键定理缺少证明
- 证明有严重逻辑错误
- 数学工具使用错误
- 证明难以理解
