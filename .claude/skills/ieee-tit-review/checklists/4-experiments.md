# 实验可重复性检查清单 / Experimental Reproducibility Checklist

## 目的 (Purpose)

检查论文中的实验/数值结果是否可重复，是否支持理论分析。

**重要说明**: IEEE TIT 是理论期刊，实验不是必需的。如果论文是纯理论论文，可以跳过此检查清单。

## 使用方法 (How to Use)

1. 确认论文是否包含实验/数值结果
2. 如果有，逐项检查以下内容
3. 记录发现的问题

---

## 0. 实验必要性评估 / Necessity of Experiments

### 0.1 实验目的 (Purpose of Experiments)

- [ ] **验证理论预测**: 实验用于验证理论分析的正确性
- [ ] **展示理论洞察**: 实验用于展示理论结果的实际意义
- [ ] **性能对比**: 实验用于与现有方法对比性能
- [ ] **参数影响分析**: 实验用于分析参数对性能的影响

**IEEE TIT 特色**:
- ⚠️ TIT 是理论期刊，实验不是必需的
- ✅ 如果有实验，必须用于**验证理论预测**或**展示理论洞察**
- ❌ 拒绝纯实验论文，没有理论贡献
- ✅ 期望实验结果与理论分析一致，或解释不一致的原因

---

### 0.2 实验与理论的关系 (Relationship Between Experiments and Theory)

- [ ] **支持理论**: 实验结果支持理论分析
- [ ] **一致性**: 实验结果与理论预测一致
- [ ] **不一致性解释**: 如果不一致，有合理的解释
- [ ] **理论指导**: 理论分析指导实验设计

**常见问题**:
- 实验结果与理论预测不一致，但未解释原因
- 实验与理论脱节，实验没有验证理论结果
- 实验过于简单，无法充分验证理论

---

## 1. 实验设置描述 / Experimental Setup Description

### 1.1 问题设置 (Problem Setup)

- [ ] **问题描述**: 清楚描述实验要解决的问题
- [ ] **参数设置**: 明确说明所有参数的取值
- [ ] **系统配置**: 说明系统的配置（如信道模型、噪声模型）
- [ ] **假设条件**: 说明实验中的假设条件

**必需信息**:
- 问题的具体设置（如信道类型、编码方案）
- 所有参数的取值和单位
- 系统的配置和假设

**常见问题**:
- 参数设置不完整
- 系统配置描述不清
- 假设条件未说明

---

### 1.2 实验环境 (Experimental Environment)

- [ ] **硬件环境**: 说明硬件配置（如 CPU、GPU、内存）
- [ ] **软件环境**: 说明软件环境（如操作系统、编程语言、库版本）
- [ ] **随机种子**: 说明是否使用固定随机种子
- [ ] **运行时间**: 说明实验的运行时间

**推荐信息**:
- 硬件: CPU 型号、GPU 型号、内存大小
- 软件: 操作系统、Python/MATLAB 版本、关键库版本
- 随机性: 是否使用固定随机种子，种子值是多少

**常见问题**:
- 未说明硬件和软件环境
- 未说明随机种子，导致结果不可重复
- 未说明运行时间，无法评估计算复杂度

---

### 1.3 数据集 (Dataset)

- [ ] **数据集描述**: 清楚描述使用的数据集
- [ ] **数据集来源**: 说明数据集的来源（公开数据集或自生成）
- [ ] **数据集规模**: 说明数据集的规模（样本数、维度等）
- [ ] **数据预处理**: 说明数据预处理方法
- [ ] **数据划分**: 说明训练集、验证集、测试集的划分

**对于公开数据集**:
- 提供数据集名称和版本
- 提供数据集的获取链接

**对于自生成数据集**:
- 说明数据生成方法
- 说明数据的统计特性
- 如果可能，提供数据或数据生成代码

**常见问题**:
- 未说明数据集来源
- 未说明数据预处理方法
- 未说明数据划分方法

## 3. 基线方法 / Baseline Methods

### 3.1 基线选择 (Baseline Selection)

- [ ] **基线方法列表**: 列出所有基线方法
- [ ] **基线合理性**: 基线方法的选择合理（包含最新的 SOTA 方法）
- [ ] **基线描述**: 清楚描述每个基线方法
- [ ] **基线来源**: 说明基线方法的来源（论文引用）

**推荐基线**:
- 经典方法（如 Shannon 界）
- 最新的 SOTA 方法
- 简单的启发式方法（作为下界）
- 理论最优方法（作为上界）

**常见问题**:
- 基线方法过时，未包含最新方法
- 基线方法选择不合理
- 基线方法描述不清

---

### 3.2 基线实现 (Baseline Implementation)

- [ ] **实现来源**: 说明基线方法的实现来源（官方代码、自己实现）
- [ ] **实现正确性**: 验证基线方法的实现正确性
- [ ] **公平对比**: 确保与基线方法的对比公平（相同的实验设置）

**对于官方代码**:
- 提供代码链接和版本
- 说明是否修改了代码

**对于自己实现**:
- 说明实现依据（论文、伪代码）
- 验证实现的正确性（如复现论文结果）

**常见问题**:
- 基线方法实现错误
- 对比不公平（不同的实验设置）
- 未说明实现来源

---

## 4. 评估指标 / Evaluation Metrics

### 4.1 指标定义 (Metric Definition)

- [ ] **指标列表**: 列出所有评估指标
- [ ] **指标定义**: 清楚定义每个指标
- [ ] **指标合理性**: 指标的选择合理（与问题相关）
- [ ] **指标计算**: 说明指标的计算方法

**常用指标**:
- 容量 (Capacity)
- 错误概率 (Error Probability)
- 吞吐量 (Throughput)
- 延迟 (Latency)
- 复杂度 (Complexity)

**常见问题**:
- 指标定义不清
- 指标选择不合理
- 指标计算方法未说明

---

### 4.2 统计显著性 (Statistical Significance)

- [ ] **多次运行**: 实验运行多次（至少 3-5 次）
- [ ] **均值和方差**: 报告均值和标准差/方差
- [ ] **误差棒**: 图表中包含误差棒或置信区间
- [ ] **显著性检验**: 进行统计显著性检验（如 t 检验）

**推荐做法**:
- 运行至少 5 次，报告均值和标准差
- 在图表中显示误差棒或置信区间
- 对关键结果进行显著性检验

**常见问题**:
- 只运行一次实验
- 未报告方差或标准差
- 图表中没有误差棒
- 未进行显著性检验

---

## 5. 结果展示 / Results Presentation

### 5.1 图表质量 (Figure and Table Quality)

- [ ] **图表清晰**: 图表清晰、专业
- [ ] **标题完整**: 图表标题完整、自解释
- [ ] **坐标轴标注**: 坐标轴有标签和单位
- [ ] **图例清晰**: 图例清晰、易读
- [ ] **颜色选择**: 颜色选择合理（考虑色盲友好）

**图表要求**:
- 矢量图（PDF、EPS）而非位图（PNG、JPG）
- 字体大小适中（至少 10pt）
- 线条粗细适中
- 颜色对比度足够

**常见问题**:
- 图表模糊（使用位图）
- 字体过小，难以阅读
- 颜色对比度不足
- 图例不清晰

---

### 5.2 结果分析 (Results Analysis)

- [ ] **结果描述**: 清楚描述实验结果
- [ ] **结果解释**: 解释实验结果的含义
- [ ] **与理论对比**: 将实验结果与理论预测对比
- [ ] **趋势分析**: 分析结果的趋势和规律
- [ ] **异常解释**: 解释异常结果或不一致之处

**推荐结构**:
1. 描述实验结果（定量）
2. 解释结果的含义（定性）
3. 与理论预测对比
4. 分析趋势和规律
5. 解释异常或不一致

**常见问题**:
- 只展示结果，不分析
- 未与理论预测对比
- 未解释异常结果
- 分析过于简单

---

## 特别说明 / Special Notes

**对于纯理论论文**:

- 在评审报告中说明"本文是纯理论论文，不需要实验验证"
- 跳过此检查清单

**对于有实验的论文**:
- 实验必须用于验证理论预测或展示理论洞察
- 实验结果应与理论分析一致，或解释不一致的原因
- 实验不能代替理论分析
